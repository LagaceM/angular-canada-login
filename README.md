# How to run

1. Generate a SSL certificate for localhost. I used mkcert found instruction how to generate here: https://web.dev/articles/how-to-use-local-https
2. In `angular.json` update `sslCert` and `sslKey` to point to your certificate.
3. Run `npm install` & `npm run start` to install and run the project.
4. Open browser console to see exception.
5. Click on the "Sign In" button
